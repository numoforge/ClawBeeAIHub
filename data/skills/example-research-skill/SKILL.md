# Example Research Skill

## When to use

Use this skill when a task asks for research, comparison, or verification of facts.

## Instructions

1. Search for primary sources first (official docs, repos, standards).
2. Read the source; do not rely on summaries.
3. Label every claim verified, reported, or assessment.
4. Never invent a fact, URL, number, or quotation.
5. If a source cannot be read, say so and do not guess.
